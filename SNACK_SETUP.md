# Login Vault - Expo Snack Demo

## Creating Your Snack

To create the live Expo Snack demo, follow these steps:

### Step 1: Go to Expo Snack

Visit [snack.expo.dev](https://snack.expo.dev)

### Step 2: Copy the Demo Code

Copy all the code from `snack-demo.js` in this folder and paste it into the Snack editor.

### Step 3: Save the Snack

1. Click the **Save** button in the top-right
2. Sign in with your Expo account (or create one)
3. Name it: `login-vault-demo`
4. Copy the generated URL (it will look like: `https://snack.expo.dev/@youruser/login-vault-demo`)

### Step 4: Add to Portfolio

Once you have your Snack URL, you can:

**Option A: Embed as iframe in your portfolio page**

```tsx
<iframe
  src="https://snack.expo.dev/embedded/@youruser/login-vault-demo?platform=web"
  style={{
    width: "100%",
    height: "700px",
    border: "none",
    borderRadius: "12px",
  }}
/>
```

**Option B: Add a link**

```tsx
<a href="https://snack.expo.dev/@youruser/login-vault-demo" target="_blank">
  View Live Demo
</a>
```

**Option C: Use the pre-made HTML page**
The `snack-demo.html` file is ready to use - just update the Snack URL with your own.
